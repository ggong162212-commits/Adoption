관리자 연결

이 화면은 천보금 입양 사이트에 아이들을 등록하는 곳입니다.
GitHub 토큰을 한 번 등록하면 이 기기에 저장되어, 다음부터는 바로 열립니다.

토큰은 비밀번호와 같습니다. 본인 기기에만 저장하세요. 공용 PC에서는 사용을 마친 뒤 반드시 토큰 지우기를 눌러 주세요.
  1. GitHub → 프로필 → Settings
  2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token 클릭
  4. Repository access → Only select repositories → Adoption 만 선택
  5. Permissions → Repository permissions → Contents 를 Read and write 로
  6. Expiration 은 90일 정도로 두고 생성 → 토큰(github_pat_…) 복사
