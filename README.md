# 천보금 입양

유기견 입양을 위한 모바일 사이트. 관리자가 **폰에서 증명사진을 올리면 바로 사이트에 반영**됩니다.

- 공개 사이트 — <https://ggong162212-commits.github.io/Adoption/>
- 관리자 화면 — <https://ggong162212-commits.github.io/Adoption/admin.html>

서버가 없습니다. 사진과 정보는 이 저장소에 파일로 저장되고, GitHub Pages가 그대로 보여줍니다.

방문자는 상단에서 **전체 보기 / 방별 보기**를 고를 수 있고, 우측 위 버튼으로 밝은 화면 · 어두운 화면을 전환할 수 있습니다.

## 디자인 방향

방 이름이 소장님방 · 거실 · 마루 · 마당입니다. 시설이 아니라 **한 집**이라서, 화면도 보호소 안내가 아니라 집의 방 안내도처럼 잡았습니다.

- 바탕은 연한 세이지 화이트(`#F3F5EF`), 글자는 짙은 올리브(`#1C2119`), 포인트는 잎사귀 그린(`#3E6B4C`), 햇빛 앰버(`#C98A2B`)는 공지·경고에만 아주 조금.
- 제목은 **Hahmlet**(획 대비가 있는 한글 명조), 본문과 UI는 **IBM Plex Sans KR**.
- 방 카드에는 그 방에 사는 아이들 얼굴이 겹쳐진 띠가 붙습니다. 폴더 목록이 아니라 가족사진처럼 읽히도록.
- **입양 가능**은 이 사이트의 기본 상태라 배지를 달지 않습니다. 진행중 · 임보중 · 입양 완료일 때만 표시됩니다.

## 처음 한 번만: 관리자 토큰 발급

관리자 화면에서 사진을 저장하려면 GitHub 토큰이 필요합니다. **폰에서 한 번만** 등록하면 계속 쓸 수 있습니다.

1. GitHub → 프로필 → **Settings**
2. 맨 아래 **Developer settings** → **Personal access tokens** → **Fine-grained tokens**
3. **Generate new token**
4. **Repository access** → `Only select repositories` → **Adoption** 만 선택
5. **Permissions** → Repository permissions → **Contents** 를 `Read and write` 로
6. **Expiration** 은 90일 정도 → 생성
7. 나온 토큰(`github_pat_…`)을 복사해서 관리자 화면에 붙여넣기

> 만료되면 관리자 화면이 토큰 등록 화면으로 돌아갑니다. 같은 절차로 새로 발급하면 됩니다. 등록된 아이들 정보는 사라지지 않습니다.

### 토큰 안전하게 쓰기

- 토큰은 **비밀번호와 같습니다.** 본인 폰에만 저장하세요.
- 권한을 **Adoption 저장소 하나 · Contents 만** 으로 좁혀 두면, 최악의 경우에도 피해가 이 저장소에 한정됩니다.
- 공용 PC에서 썼다면 **설정 탭 → 토큰 지우기**를 꼭 누르세요.
- 토큰이 새어 나갔다고 판단되면 GitHub의 Fine-grained tokens 목록에서 **Revoke** 하세요. 즉시 무효화됩니다.
- `admin.html` 주소는 누구나 열 수 있지만, **토큰 없이는 아무것도 저장되지 않습니다.**

## 사용법

### 아이 등록하기

1. **등록** 탭 → `촬영` 또는 `앨범`
2. 사진을 손가락으로 옮기고 두 손가락으로 확대해 **증명사진** 구도를 잡습니다
3. 이름 · 방 · 성별 · 추정 나이 · 상태 · 특징 입력
4. **저장하기**

저장하면 GitHub에 커밋되고, **약 1분 뒤** 공개 사이트에 나타납니다 (GitHub Pages 재빌드 시간).

### 증명사진을 더 예쁘게

`✨ 증명사진 프롬프트 복사` 버튼을 누르면 [`docs/id-photo-prompt.txt`](docs/id-photo-prompt.txt) 의 프롬프트가 복사됩니다.
AI 이미지 도구에 원본 사진과 함께 붙여넣으면 스튜디오 배경의 증명사진이 나옵니다. **아이의 원래 얼굴을 바꾸지 않도록** 설계된 프롬프트입니다. 결과물을 다시 등록 화면에 올리면 됩니다.

### 수정 · 삭제

**목록** 탭에서 아이를 누르면 수정 화면으로 들어갑니다. 사진을 다시 고르면 교체되고, 그대로 두면 기존 사진이 유지됩니다. 삭제하면 사진 파일도 함께 지워집니다.

### 방 관리

**방** 탭에서 아이콘 · 이름 · 색을 바꿀 수 있습니다.
- 방 이름을 바꾸면 **그 방의 아이들도 자동으로 따라 옮겨집니다.**
- 아이가 남아 있는 방은 삭제할 수 없습니다.

### 사이트 설정

**설정** 탭에서 사이트 제목 · 부제 · 공지 · 연락처(전화 / 카카오 / 인스타그램)를 바꿉니다. 연락처를 비워 두면 해당 버튼이 표시되지 않습니다.

## 구조

```
index.html            공개 사이트
admin.html            관리자 화면 (noindex)
assets/
  base.css            공통 스타일 + 증명사진 카드
  idcard.js           증명사진 카드 마크업 + 캔버스 PNG 합성 (공개/관리자 공용)
  app.js              공개 사이트 로직
  admin.js            관리자 로직
  cropper.js          정사각 터치 크롭 (외부 라이브러리 없음)
  gh.js               ★ 유일한 저장 계층 — GitHub Contents API
data/
  rooms.json          방 목록
  dogs.json           강아지 목록
  site.json           사이트 제목 · 공지 · 연락처
photos/               업로드된 증명사진 (900×900 webp)
docs/
  id-photo-prompt.txt 증명사진 생성 프롬프트
```

### 강아지 데이터 (`data/dogs.json`)

```json
{
  "id": "d-20260728-a3f1",
  "name": "마루",
  "room": "마루",
  "gender": "남",
  "ageText": "11살 이상 추정",
  "note": "16년도 이전 입소",
  "status": "adoptable",
  "photo": "photos/d-20260728-a3f1.webp",
  "createdAt": "2026-07-28T10:00:00Z",
  "updatedAt": "2026-07-28T10:00:00Z"
}
```

`status` — `adoptable`(입양 가능) · `pending`(입양 진행중) · `foster`(임시보호중) · `adopted`(입양 완료)

### 저장 계층 교체

봉사자 여러 명이 올려야 하거나 즉시 반영이 필요해지면, `data/*.json` 스키마는 그대로 두고 **`assets/gh.js` 만** 같은 인터페이스로 갈아끼우면 됩니다 (Supabase 등). 그래서 저장 코드를 이 한 파일에 몰아 두었습니다.

```powershell
cd C:\Users\goeun.sun\project\Adoption
python -m http.server 8080
```

<http://localhost:8080/> 접속. 개발자도구 모바일 뷰로 보면 실제 폰과 비슷하게 확인됩니다.
관리자 화면도 `http://localhost:8080/admin.html` 로 열리며, 토큰만 있으면 **로컬에서도 실제 저장소에 바로 커밋**됩니다.

## 알아둘 점

- 사진은 업로드 시 **900×900 WebP(약 80KB)** 로 줄여 저장합니다. WebP를 못 만드는 브라우저에서는 JPEG로 자동 대체합니다.
- 카드가 정사각형인 이유는 [`docs/id-photo-prompt.txt`](docs/id-photo-prompt.txt) 의 출력 규격이 `1:1 square` 이기 때문입니다. 프롬프트를 바꾸면 규격도 함께 맞춰야 합니다.
- git 히스토리에 사진이 남으므로, **삭제해도 저장소 용량은 줄지 않습니다.** 500마리여도 50MB 수준이라 문제는 없습니다.
- 공개 사이트는 데이터를 캐시 없이 불러오지만, GitHub Pages 재빌드 전에는 이전 내용이 보일 수 있습니다.
